# quehacer
A small todo list app with different features, such as:

<ul>
    <li>Creating, modifying and deleting projects.</li>
    <li>Creating, modifying and deleting tasks inside projects.</li>
    <li>Setting and modifying the urgency status of a task.</li>
    <li>Mark the task as 'pending', 'working on it' and 'done'.</li>
</ul>
